## VeloStaffChat

A simple Minecraft Velocity proxy plugin to allow staff members to communicate privately in-game.

> [!NOTE]
> Please install [modrinth.com/plugin/signedvelocity](https://modrinth.com/plugin/signedvelocity) may
> be required to prevent newer clients from getting kicked when trying to write a staff-only message.

### Usage

Use `/staff <message>` or simple write `# <message>` in the chat to send staff-only messages.
